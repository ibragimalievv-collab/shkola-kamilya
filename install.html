Как установить и проверить «Школу Камиля»

Играть и проверять уровни можно прямо из браузера. Чтобы открывать игру одним нажатием, добавьте её значок на своё устройство.

Открыть игруПроверить все уровни

Mac · Safari

  1. Откройте игру в Safari.
  2. В строке меню наверху экрана нажмите Файл → Добавить в Dock → Добавить.
  3. Если такого пункта нет, откройте меню  → «Об этом Mac». Команда доступна с macOS Sonoma 14. На более ранней версии можно сохранить игру в закладки сочетанием ⌘D.

iPhone и iPad · Safari

  1. Откройте игру в Safari на телефоне или планшете.
  2. Нажмите Поделиться (квадрат со стрелкой вверх). Если кнопки не видно, откройте меню страницы возле адресной строки.
  3. Прокрутите меню до На экран «Домой». Если пункта нет, добавьте его через «Изменить действия». Включите «Открыть как веб-приложение», если такой переключатель есть, и нажмите Добавить.

Android · Chrome

  1. Откройте игру в Chrome.
  2. Рядом с адресной строкой нажмите ⋮ → Установить и создать ярлык → Установить. В некоторых версиях доступен пункт «Установить приложение».
  3. Откройте игру с появившегося значка при включённом интернете.

Имя героя

После рисунка нажмите «Готово», впишите имя в поле Своё имя героя и нажмите Сохранить имя. Если герой уже есть, на карте откройте «Настройки для родителей» → «Ребёнок» → «Изменить имя героя». Если рисование пропустили, в том же месте есть «Нарисовать героя».

Проверить на своём телефоне

  1. Откройте самопроверку и оставьте вкладку открытой до надписи «ВСЁ В ПОРЯДКЕ». Внизу появятся количество проверенных уровней и число ошибок.
  2. Для проверки без сети откройте игру со значка. На карте зайдите в «Настройки для родителей» → «Настройки» → Скачать озвучку для дороги. Дождитесь подтверждения загрузки всех наборов.
  3. Включите авиарежим, выключите Wi-Fi и перезапустите игру со значка. Закончите урок, откройте игру ещё раз и проверьте, что звёзды сохранились.

Автонажатия на Android с компьютера Mac

  1. На Mac введите в адресную строку Safari studio.maestro.dev/MaestroStudio.dmg, чтобы скачать Maestro Studio для macOS. Откройте файл и перетащите приложение в «Программы».
  2. Создайте на Mac папку «Проверка игры». Скачайте сценарий Maestro в эту папку.
  3. На Android в настройках «О телефоне» найдите «Номер сборки» (на некоторых моделях в разделе со сведениями о ПО) и нажмите семь раз. В «Параметрах разработчика» включите «Отладка по USB».
  4. Подключите разблокированный Android кабелем передачи данных и разрешите отладку на телефоне. Откройте Chrome и завершите его первоначальную настройку, если потребуется.
  5. В Maestro Studio выберите Choose new workspace location и папку с файлом. Вверху выберите свой телефон, откройте файл сценария и нажмите Run Locally или Run Test.

Сценарий открывает раскраску, нажимает подсказку, возвращается в школу и запускает встроенную проверку заданий. Снимок результата сохраняется в конце. Для проверки камеры, записи голоса и возврата после звонка используйте соответствующие функции на самом телефоне.
